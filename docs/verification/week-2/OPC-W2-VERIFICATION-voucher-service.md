## 3. 关键 Mockito 模式

### 3.1 useGeneratedKeys 回填主键

```java
private static final AtomicLong NEXT_ID = new AtomicLong(100L);

@BeforeEach
void setupAutoKeyBehavior() {
    when(mapper.insert(any(OpcFinanceVoucher.class)))
            .thenAnswer(inv -> {
                OpcFinanceVoucher v = inv.getArgument(0);
                v.setId(NEXT_ID.getAndIncrement());
                return 1;
            });
}
```

`opc_finance_voucher` mapper XML 使用 `useGeneratedKeys="true" keyProperty="id"`（参考 W2.1 TaxReport
同模式）。`thenAnswer` 在 insert 返回前给入参对象的 `id` 字段赋值，模拟 MyBatis 自动回填主键。

### 3.2 ArgumentCaptor 验证状态机写入字段

```java
ArgumentCaptor<OpcFinanceVoucher> captor = ArgumentCaptor.forClass(OpcFinanceVoucher.class);
verify(mapper).update(captor.capture());
OpcFinanceVoucher v = captor.getValue();
assertEquals(VOUCHER_ID, v.getId());
assertEquals("REVIEW", v.getStatus());
assertEquals("bob", v.getReviewedBy());
assertNotNull(v.getReviewedTime());
assertEquals("bob", v.getUpdateBy());
```

reviewPass / reviewReject / post 都用 ArgumentCaptor 验证 4-5 个字段同时写入，确保状态机迁移的
完整性。

### 3.3 状态机非法迁移保护（post）

```java
when(mapper.selectById(VOUCHER_ID)).thenReturn(v); // v.status = "DRAFT"

assertThrows(OpcException.class, () -> service.post(VOUCHER_ID, "carol"));
verify(mapper, never()).update(any(OpcFinanceVoucher.class));
```

post() 先 selectById 校验 status 必须是 REVIEW，否则抛异常且 **不调** mapper.update。测试同时
验证异常路径和「未触发写库」的副作用。

## 4. 不变量 / 边界断言

| 断言 | 测试方法 |
|---|---|
| `voucherCode.startsWith("V")` + 长度 = 15 (V + yyyyMMdd + 6 位) | `create_voucherCodeFormat` |
| `voucherCode` 前缀 = `V + LocalDate.now()` 的 yyyyMMdd | `create_voucherCodeFormat` |
| `service.create()` 强制覆盖 status 为 DRAFT（即使调用方传 POSTED） | `create_statusAlwaysDraft` |
| `reviewPass` 写入 5 字段：id / status=REVIEW / reviewedBy / reviewedTime / updateBy | `reviewPass_setsAllFields` |
| `reviewReject` 写入 6 字段：id / status=REJECTED / reviewedBy / reviewedTime / remark=opinion / updateBy | `reviewReject_setsAllFields` |
| `reviewReject(opinion=null)` 不擅自填默认值 | `reviewReject_nullOpinion` |
| `post(凭证不存在)` → 抛「凭证不存在」+ `verify(never()).update(...)` | `post_voucherNotFound_throws` |
| `post(非 REVIEW 状态)` → 抛「未通过审核」+ `verify(never()).update(...)` | `post_statusDraft_throws` 等 3 例 |
| `post(REVIEW)` 写入 5 字段：id / status=POSTED / postedBy / postedTime / updateBy | `post_statusReview_success` |
| post 不修改原 voucher 对象（service 新建 v 写库） | `post_doesNotMutateOriginalVoucher` |
